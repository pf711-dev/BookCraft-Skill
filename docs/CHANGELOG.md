# 更新日志 (Changelog)

本项目的所有重要变更记录于此文件。
格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)。

## [1.4.0] - 2026-11-10

统一预检与图片型 PDF 支持：**翻译前一次预检确认（时间/token/输出预估），图片型 PDF 能否翻译由模型视觉能力决定，用户无需区分 PDF 类型**

### 新增

#### 全格式统一预检（SKILL.md 步骤 1.2）
- **预检报告**：extract 后、翻译前向用户展示——翻译类型（默认中英对照易搞错，重点确认）、输出文件名、工作目录、当前模型与视觉能力、预计耗时（批次÷并发4）、token 消耗估算（硬数据）与参考价、章节预览（合并原"人工核对章节"环节）
- **视觉探测**：PDF 含扫描页时读一张 `scans/` 截图测试模型视觉能力；无视觉时给出两个选项（换多模态模型 / 跳过扫描页只译文本）
- **唯一确认点**：确认后一口气跑完不再中断（质量校验回退除外）
- **预估字段**：meta.json 与 extract stdout 新增 `total_words` / `est_batches`（3000 词/批口径），EPUB / Markdown / PDF 三种格式统一

#### 图片型 PDF（扫描版）支持
- **章节 fallback**：自动检测不到标题（无文本层）时不再 SystemExit，回退整本单章（id=book，书名做章名），扫描页截图照常导出；用户显式 `--chapters pattern` 无匹配时仍报错
- **中性化提示**：扫描页占比 >60% 的警告改为信息性提示（是否可译由预检视觉探测决定），不再建议"先 OCR 后重跑"
- **chapter_start 章节重建**：识图翻译时标记章节起始页（`"chapter_start": true` + `"chapter_title"`），build 时自动切出新章——整本扫描书不再几百页挤一个 XHTML
- build 输出新增 `chapters_xhtml`（切分后实际章数，完整性校验用）

### 变更
- SKILL.md：新增步骤 1.2 预检与确认（含估算系数表：输入≈词数×1.3，输出≈×2/×3.3，识图每页≈2k tok）；步骤 3.5 增加章节重建规则；对话规则改为"预检确认后跑完"；边界更新为"PDF 能否翻译取决于模型视觉能力"；版本 1.3.0 → 1.4.0
- pdf_build.py 章节组装重构为动态分章（flush_chapter），无 chapter_start 时输出与 1.3.0 完全一致（14+24 项回归全过）

## [1.3.0] - 2026-11-07

表格与公式支持：**表格 = 真翻译（表头/单元格文字）；公式 = 保护性保留（数学不该翻译，防模型改写）**

### 新增

#### Markdown
- **公式占位符保护**：`$...$` / `$$...$$` / `\(...\)` / `\[...\]` 四种公式在翻译前替换为 `⟦Mn⟧` 占位符，译文中的占位符在组装时自动还原为公式原文——公式不再被模型改写破坏
  - 类 pandoc 启发式识别：货币写法（如 `costs $100 and $200`）不误伤
  - 代码围栏与行内代码中的 `$`（shell 变量、价格示例）不受影响
  - 宽容还原：容忍翻译模型对占位符的轻微改写（全角括号 `[M1]`、`【M1】`、增删空白、大小写）
  - **公式兜底**：译文丢失任一占位符 → 该段自动回退英文原文，公式绝不因翻译丢失
  - 引用块（`>`）内的块级公式还原时自动补引用前缀，不破坏 Markdown 结构
- **表格逐格翻译**：整表作为一个翻译单元（表头 + 各行，保证列语义——如 "Q1" 知道是季度列）
  - 提取侧：识别 `<table>` 生成结构化翻译单元（`[TABLE]` + `Header:`/`Row:` 行格式）
  - 写回侧：单元格级替换并重建 `|` 表格结构与对齐行；`\|` 转义竖线单元格正确处理
  - bilingual 模式在原表后附中文表副本；chinese_only 模式原位替换单元格
  - **表格兜底**：译文列数不匹配或格式无法解析 → 整表回退英文，不丢内容

#### PDF
- **公式行 verbatim 保护**：数学符号密度检测（≥3 个符号，或 ≥2 个且密度 ≥8%；覆盖 ∑∫∏√±≤≥≠≈∞∂∇、希腊字母等）→ 公式行保留原文不翻译。**不做公式识别重建**（超出架构定位）
- **字体乱码兜底**：私有字体无 ToUnicode 映射时公式被提取为密集 `·`，此类乱码行同样 verbatim 保护
- **数据表行判定增强**：数字占比检查从 >4 token 放宽至 ≥3 token（修复 `Acme Corp $1,200 +15%` 类短数据行漏判）
- **表头翻译保障**：跨页段落合并阶段排除 verbatim 候选块，表头行不再被数据行吞并，始终进入翻译流（数据行保留原文、表头正常翻译）
- **verbatim 聚合渲染**：连续数据行/公式行在 EPUB 与 Markdown 备份中合并为单一数据块，视觉完整且不破坏译文索引

### 修复

- Markdown：含转义美元 `\$` 的段落（如 `\$50`）因 mistune unescape 差异导致写回时永远匹配不上、无法翻译——现已统一处理
- Markdown：blockquote 与其内部 `<p>` 对同一段文本重复提取，产生重复段落——引用块现整体作为单一单元
- Markdown 表格：译文解析顺序错误导致含 `\|` 转义的单元格被错位拆分——已改为先保护转义再切分
- install.sh：Homebrew Python（PEP 668 受管环境）下 `pip install` 失败导致整个安装中止——现为逐包检测缺失依赖，安装失败仅提示不阻断

### 改进

- install.sh：依赖已全部安装时自动跳过安装步骤；可选依赖（mistune/pymupdf/ebooklib）缺失时给出能力降级提示
- 提取阶段输出新增 `formulas_protected` / `table_units` 统计，便于翻译前确认保护是否生效

### 文档与测试

- SKILL.md → v1.3.0：新增表格/公式能力说明与边界章节；翻译 Prompt 新增第 6 条（⟦Mn⟧ 原样保留）与第 7 条（[TABLE] 格式遵循）
- 新增结构层回归测试 38 项（`tests/`）：
  - `test_markdown.py`：24 项（公式识别/还原/校验、表格单元/序列化/解析、双语与纯中文端到端、占位符丢失回退、表格解析失败回退）
  - `test_pdf.py`：14 项（verbatim 各形态判定、章节数/段落数/verbatim 数/译文映射率端到端；PDF 动态生成，不入库二进制）
